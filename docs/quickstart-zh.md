# 中文快速上手

Video Knowledge Studio 是本地学习与视频制作应用，也提供给 Agent 调用的工具。
Agent 是能按任务调用工具的助手，例如帮助查找资料；它不等于应用里已经内置搜索。

| 术语 | 白话含义 | 例子 | 首次出现 | 自评 |
| --- | --- | --- | --- | --- |
| Agent | 能调用工具协助完成任务的助手 | 帮忙查找并比较视频来源 | 开头 | 会 / 模糊 / 不会 |
| yt-dlp | 可选的视频网站资料获取工具 | 用关键词查找视频标题和链接 | 当前边界 | 会 / 模糊 / 不会 |
| 课程包 | 包含视频、课程目录和笔记的文件夹 | `packs/raft-demo-en/` | 第 2 步 | 会 / 模糊 / 不会 |
| 时间戳 | 视频中的具体时间位置 | 点击 `00:05` 跳回对应画面 | 第 2 步 | 会 / 模糊 / 不会 |
| 模型服务 | 负责回答问题的程序或在线接口 | 本机 Codex 或兼容接口 | 第 3 步 | 会 / 模糊 / 不会 |
| 制作规格 | 描述每页画面、讲稿和来源的结构化文件 | 一个经过审核的 `spec.json` | 第 4 步 | 会 / 模糊 / 不会 |
| 检查项 | 在渲染前检查内容或制作条件的规则 | 检查引用和练习是否完整 | 第 4 步 | 会 / 模糊 / 不会 |

1. 在仓库目录运行 `python -m vks`，打开终端显示的地址。Docker 用户可参考
   [Docker 指南](docker.md)。
2. 打开示例课程包，播放视频，点击笔记中的时间戳查看对应片段。导入个人视频只会
   创建笔记骨架，需要根据转录和画面补齐内容。
3. 配置模型服务后选中笔记提问。默认自动模式可能回退到离线演示；请查看实际回答
   的服务标识。具体设置见 [配置指南](configuration.md)。
4. 在制作页编辑并审核制作规格，再创建流程：生成分镜 → 检查项 → 渲染。每一步
   完成后需要人工查看并点击继续；失败或取消后可重试当前步骤。

**目前的边界：** Agent 可通过可选的 `yt-dlp` 搜索 B 站/YouTube 元数据，但平台可能
拒绝访问；来源筛选、转写、跨视频整合与完整笔记生成仍需要外部工具或人工参与。
它还不能从一句学习目标全自动生成并验证整门课程。
Agent 可通过 [MCP 工具](agent-mcp.md) 调用现有功能。
